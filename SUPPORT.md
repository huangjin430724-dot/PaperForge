# Support

Thanks for using PaperForge.

## Before Asking for Help

Please check:

- [README.md](README.md) or [README_ZH.md](README_ZH.md)
- [CHANGELOG.md](CHANGELOG.md)
- Existing GitHub issues

For local verification, run:

```bash
npm run check
```

For Figure Agent asset problems, run:

```bash
npm run check:figures
```

## Where to Ask

- Use **Bug report** for reproducible crashes, broken workflows, or incorrect behavior.
- Use **Feature request** for new workflow ideas.
- Use **Figure Agent issue** for scientific figure planning, SVG generation, QA, registry, reports, or demo assets.

## Helpful Details

When asking for help, include:

- Operating system and Node.js version.
- PaperForge commit hash.
- Command output or browser console logs.
- Screenshots for UI problems.
- Relevant generated artifact paths, such as `.figure.json`, `.figure.qa.json`, `figures/index.json`, or `figure_report.md`.

Do not share API keys, private manuscripts, unpublished paper content, or collaboration tokens in public issues.
